# 6-DOF Hand-Tracking Arm Media

- `overall-movement.mp4`: browser-compatible H.264/AAC MP4 copy of `IMG_8964.MOV`, labeled Overall movement.
- `wrist-rotation.mp4`: browser-compatible H.264/AAC MP4 copy of `IMG_8962.MOV`, labeled Wrist rotation.
- `overall-poster.jpg` and `wrist-poster.jpg`: still frames from the corresponding clips, approximately 0.5 seconds in.
- `build-photo.jpg`: original bytes of the supplied `IMG_9573.JPG`.
- `arm-cad-cover.png`: previously supplied CAD assembly, retained as the project cover.

The videos retain the entire original clips and their primary audio tracks. Orientation has been applied during encoding for browser compatibility, with the longer edge capped at 1280 pixels. MP4 fast-start metadata permits streaming. No video content is cropped or trimmed. Both players use native controls and start only when selected; starting one pauses the other.
