# Lightweight 3D-Printed Bridge

Additive Manufacturing Processes final project. The challenge was to create the lightest 3D-printed bridge capable of holding a 20 lb load.

- Finished structure: under 12 g, excluding support material.
- Print supports: 3 g, removed before loading.
- Load supported: 20 lb.
- Result: course record for the lightest successful structure; the project author confirms that the record remains unbeaten.

`bridge-design.webp` is a lossless conversion of the supplied `Screenshot 2025-12-02 023627.png`; decoded pixels were verified to match. It is a CAD view, not a photograph of the printed bridge. No material, dimensions, infill percentage, print settings, or numerical analysis results have been inferred.
