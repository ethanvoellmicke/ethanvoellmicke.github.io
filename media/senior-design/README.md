# RTX Senior Design Project Media

This section includes CAD designs, engineering drawings, prototype documentation, and the team’s real CNC-machined valve assembly.

- `valve-assembly-render.svg` is a legacy asset filename. The image shows the physical valve assembly that the team CNC-machined and assembled. Website captions identify it as manufactured hardware.
- `early-flow-simulation.png` is the original supplied `Screenshot 2025-10-26 221927.png`. It shows SOLIDWORKS Flow Simulation on a very early model, with original arrows, geometry, and colors preserved. It is labeled as an early design study rather than a result for the final valve geometry.
