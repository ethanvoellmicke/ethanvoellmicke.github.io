# Vacuum-Powered Microneedle Actuators

THEAM Lab, UMass Amherst. Ethan Voellmicke: Undergraduate Researcher, April 2025–May 2026, as stated in the supplied résumé. The résumé was used only as a writing reference and is not published here.

This portfolio project describes research and concept design of vacuum-powered soft mechanisms intended for microneedle steering. It documents SOLIDWORKS CAD, material-modeling investigations, dot-density exploration, SOLIDWORKS Visualize renders, and exploration of microprinting/additive-manufacturing routes. Curved imagery is a modeled design view; no measured actuation performance or fabricated-device result is inferred from it.
